# LEAtTrace — Blockchain Intelligence & Investigation Platform

LEAtTrace is a modern, high-performance law enforcement cryptocurrency transaction tracing and blockchain intelligence dashboard.

## Features
- **Transaction Flow Tracing**: Interactive multi-hop graph visualization using Cytoscape.
- **Incident Response & SOC Dashboard**: Real-time triage, alert feeds, and threat scoring.
- **Multi-Chain Analysis**: Track Bitcoin, Ethereum, and EVM network entities.
- **Evidence & Cases**: Case management, chain-of-custody evidence logging, and audit tracking.
- **Dark Modern UI**: Built with React 18, Vite, Tailwind CSS, Lucide icons, and Recharts.

## Deployment
